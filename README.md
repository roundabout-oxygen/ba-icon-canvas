# BlueArchive Icon Canvas (v1.0.25)

ブルーアーカイブ（ブルアカ）のキャラクターアイコンを自由に配置・整列・枠囲み・テキスト編集できるキャンバス作成ツールです。

🌐 **Webアプリとしてブラウザから今すぐ利用可能**:
[https://roundabout-oxygen.github.io/ba-icon-canvas/](https://roundabout-oxygen.github.io/ba-icon-canvas/)

---

## 主な機能

1. **生徒辞書・キャラクター検索（左サイドバー）**
   - 全390名（実装済み生徒277名＋未実装NPC113名）のデータ・アイコン画像を完全収録
   - 名前検索、攻撃属性（爆発・貫通・神秘・振動）、防御属性（軽装備・重装甲・特殊装甲・弾力装甲）、部隊（STRIKER/SPECIAL）、クラス、学校による高速絞り込み
   - **「実装 / 未実装 / 全」3択セグメント切り替え**: 通常は実装済みのみ表示、NPCキャラクターのみの表示や両方表示もワンクリックで切り替え
   - キャンバスへドラッグ＆ドロップ、またはクリックで追加

2. **メインキャンバス編集**
   - アイコンの自由配置・ドラッグ移動
   - **PowerPoint風スマートガイド（スナップ吸着）**: 端や中心が揃うと赤い破線が表示されピタッと吸着
   - **囲み枠（グループコンテナ）**: 属性カラー（赤・黄・青・紫・緑・黒・白等）や透明度、枠線の太さ、角丸を自由に調整
   - **テキストボックス（タイトル・タグ・注釈）**:
     - 枠と同じように「枠線の色」「背景色」「枠線の太さ」「角の丸み」を編集可能
     - 「軽装備」「重装甲」などの属性プリセットをワンクリック適用
     - 前面へ/背面へのレイヤー順序変更
   - **配置・整列ツールバー**:
     - 複数選択（ドラッグ矩形選択、またはShift+クリック）
     - 左揃え、左右中央、右揃え、上揃え、上下中央、下揃え、水平・垂直均等整列
     - アイコンサイズ調整スライダー（48px〜100px）
     - キャンバスサイズ変更、背景色変更、グリッド表示切替、ズーム（50%〜200%）

3. **保存・エクスポート**
   - **PNG画像書き出し**: 高解像度（2倍スケール）でPNG画像として保存
   - **クリップボードコピー**: 生成画像をワンクリックでクリップボードにコピー
   - **プロジェクト保存・復元**: レイアウト状態をJSONファイルとして保存・読み込み
   - **アンドゥ / リドゥ**: Ctrl+Z / Ctrl+Y 対応

## ご利用方法

### 1. Webブラウザで使う（推奨）
PC、タブレット、スマートフォンのブラウザからインストール不要で直接利用できます：
**[https://roundabout-oxygen.github.io/ba-icon-canvas/](https://roundabout-oxygen.github.io/ba-icon-canvas/)**

### 2. ポータブル `.exe` で使う
オフライン環境などでWindowsアプリとして使いたい場合：
```bat
release\BlueArchiveIconCanvas.exe
```
インストーラー不要で、ダブルクリックするだけで単独起動します。

### 3. `start.bat` から起動する
プロジェクトフォルダ内の `start.bat` をダブルクリックすると、exeが存在する場合はexeが、ない場合はローカルプレビューサーバーが自動起動してブラウザが開きます。
