# BlueArchive Icon Canvas (v1.0.1)

ブルーアーカイブ（ブルアカ）のキャラクターアイコンを自由に配置・整列・枠囲み・編集できるPCソフトです。

---

## 主な機能

1. **生徒辞書（左サイドバー）**
   - 全275体の生徒データ・アイコン画像をローカル収録（完全オフライン動作）
   - 名前検索、攻撃属性（爆発・貫通・神秘・振動）、防御属性（軽装備・重装甲・特殊装甲・弾力装甲）、学校、役割（STRIKER/SPECIAL）による高速絞り込み
   - キャンバスへドラッグ＆ドロップで追加、またはダブルクリックで追加

2. **メインキャンバス編集**
   - アイコンのみのすっきりした配置（生徒名テキストは非表示）
   - **PowerPoint風スマートガイド（スナップ吸着）**:
     - アイコンや枠同士の端（上・下・左・右）や中央が近づくとピタッと吸着
     - 位置が揃った瞬間に赤い破線のスマートガイド線を表示
   - **囲み枠（グループコンテナ）**:
     - 添付画像のような赤枠・黄枠・青枠・緑枠をワンクリックで追加
     - 枠線の太さ・色、背景色（透明〜半透明〜ベタ塗り）を自由にカスタマイズ
     - 四隅・四辺のハンドルをドラッグして自由リサイズ
     - 枠内アイコンの「横一列整列」「グリッド整列」ボタン
   - **配置・整列ツールバー**:
     - 複数選択（範囲ドラッグ選択、またはShift+クリック）
     - 左揃え、左右中央、右揃え、上揃え、上下中央、下揃え、水平等間隔整列
     - アイコンサイズ調整スライダー（48px〜100px）
     - キャンバス背景色設定、グリッド表示切替、ズーム（50%〜200%）

3. **保存・エクスポート**
   - **PNG画像書き出し**: 高解像度（2倍スケール）でPNG画像として保存
   - **クリップボードコピー**: 生成画像をクリップボードにコピー
   - **プロジェクト保存・復元**: レイアウト状態をJSONファイルとして保存・読み込み
   - **アンドゥ / リドゥ**: Ctrl+Z / Ctrl+Y 対応

## 起動方法

### 1. ポータブル `.exe` の起動
```bat
release\BlueArchiveIconCanvas-v1.0.1.exe
```
インストーラー不要で、ダブルクリックするだけで単独起動します。

### 2. `start.bat` からの起動
フォルダ内の `start.bat` をダブルクリックすると、exeが存在する場合はexeが、ない場合はローカルプレビューサーバーが自動起動してブラウザが開きます。
